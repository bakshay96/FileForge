## 🎬 2. Canvas Studio PRO Updates (`/canvas`)

### 2.1 1-Click Aspect Ratio Swapper
- **Location**: Canvas Studio top toolbar and `Adjust` right panel.
- **Usage**: Click any ratio button (`16:9 Landscape`, `9:16 Shorts/Reels`, `1:1 Square`, `4:5 Portrait`) to dynamically resize and reframe your canvas.

### 2.2 AI Background Removal (PRO)
- **Location**: Top Navigation Bar ➔ `AI` ➔ `AI Background Removal (PRO)`.
- **Usage**: Click the menu item to isolate the main subject in your image and set background pixels to transparent (`alpha = 0`).

### 2.3 Magic Object Eraser Brush
- **Location**: Top Navigation Bar ➔ `AI` ➔ `Magic Object Eraser Brush` or click the `Eraser` icon in the left toolbar.
- **Usage**: Drag your mouse over unwanted objects or watermark text on the canvas to erase them.

### 2.4 Save & Load `.forge` Project Files
- **Location**: Top Navigation Bar ➔ `File` menu.
- **Save**: Click `Save Project (.forge)` to download a `.forge` JSON file containing all timeline tracks, text clips, color filters, and aspect ratio settings.
- **Load**: Click `Open Project (.forge)` and select your `.forge` file to restore your editing workspace instantly.

### 2.5 AI Auto-Subtitle Generator
- **Location**: Top Navigation Bar ➔ `AI` ➔ `Auto-Generate Subtitles (PRO)`.
- **Usage**: Click to automatically insert timed, styled subtitle clips onto your timeline.

## 📄 3. PDF Suite Upgrades (`/pdf`)

### 3.1 PDF OCR Text Extraction
- **Location**: `/pdf` ➔ `PDF OCR` Mode Tab.
- **Usage**: Upload a scanned PDF document and click `Extract Text (OCR)` to copy plain text to your clipboard.

### 3.2 Interactive Page Organizer
- **Location**: `/pdf` ➔ `Page Organizer` Mode Tab.
- **Usage**: Upload a PDF file to view thumbnails of individual pages. Reorder pages using drag-and-drop or rotate/delete unwanted pages before saving.

## 🖼️ 4. Image Watermark Stamper (`/convert`)

- **Location**: `/convert` ➔ `Options` ➔ Check `Stamp Image Watermark (PRO)`.
- **Usage**:
  1. Type your custom text (e.g., `© 2026 ABTech / FileForge PRO`).
  2. Adjust the opacity slider (10% to 100%).
  3. Click `Convert to WEBP/PNG/JPG` to download your watermarked image.
